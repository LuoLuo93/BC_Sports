## F31 — Shiro 3.0.1 升级（2026-09-08 完成，删除 204 行桥接）

| 项 | 内容 |
|------|------|
| pom.xml | shiro-spring-boot-web-starter 1.13.0 → **3.0.1**（原生 jakarta.servlet）；删 javax.servlet-api 依赖；删 thymeleaf-extras-shiro |
| 删除文件 | ShiroJakartaBridge.java（204 行动态代理桥接）；templates/ 目录（37 个遗留模板，全 SPA 不用） |
| ShiroConfig.java | 删 shiroFilterRegistration Bean（3.0 自动注册 Filter）；删 ShiroDialect Bean；javax.servlet.Filter → jakarta.servlet.Filter |
| SpaAuthFilter.java | 4 处 javax → jakarta import |
| UserRealm.java | ByteSource import 路径改 org.apache.shiro.lang.util.ByteSource（3.0 包迁移） |
| BCryptCredentialsMatcher.java | 同上 ByteSource 包迁移 |
| PasswordUtil.java | Shiro 3.0 移除 Md5Hash/SimpleHash → 改标准 Java MessageDigest 实现 MD5 迭代哈希（等价） |
| 收益 | 每请求省 2 个动态代理+多次反射；getSession() 不再恒 null；删 204 行维护负担；Cookie 无需手动转换；将来升 Boot 4 零改动 |

> 关键发现：Shiro 2.0 仍用 javax.servlet，**原生 jakarta 要 3.0+**。项目 JDK 21 ≥ 3.0 要求的 17，且未使用任何 3.0 已移除类。
